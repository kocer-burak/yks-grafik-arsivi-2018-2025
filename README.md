# YKS Üniversite & Bölüm Sıralama Grafikleri Arşivi (2018-2025)

Bu depoda, birden fazla YÖK Atlas veri setleri birleştirilerek hazırlanmış Türkiye'deki (neredeyse) tüm üniversitelerin ve bölümlerin YKS'nin başından bugüne 2018-2025 yılları arasındaki taban başarı sıralamalarını çizgi grafiği şeklinde gösteren yüksek çözünürlüklü (~4000x4000), sayfa başına 5x5=25 altgrafik olacak şekilde .png dosyaları yer almaktadır.
